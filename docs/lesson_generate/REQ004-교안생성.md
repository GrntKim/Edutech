| 항목 | 내용 |

본 문서는 B(매핑 에이전트)가 전달한 정방향 매핑 결과와 대상 학년 정보를 입력받아, **공식 교수학습과정안(HWP) 양식**의 틀에 맞춰 교안, 활동지, 예상 문답을 생성하는 에이전트의 요구사항을 정의한다.

본 모듈은 단발성 생성이 아니라, D(검증 에이전트)와의 재귀적 피드백 루프(최대 N회)를 통해 학년 누적 범위 위반이나 논리적 오류가 발견될 경우 retry_feedback을 반영하여 교안을 스스로 수정·개선하는 핵심 역할을 수행한다.

#### 2. 하위 기능 구성

- **LG-000**: 입출력 데이터 모델 정의 (B 및 D와의 인터페이스 계약)
- **LG-001**: 공식 교안 양식 HWP 템플릿 및 학습 목표·상중하(ABC) 평가 기준 설계
- **LG-002**: 4단계 수업 구조(동기유발-본활동-정리) 및 Gemini 기반 교사 예상 발화·오개념 지도 스크립트 생성
- **LG-003**: 정합성이 보장된 학생용 활동지(워크시트) 및 예상 문답(expected_qna) 생성
- **LG-004**: D 에이전트의 retry_feedback 반영 재귀적 재생성 로직 처리

#### 3. 데이터 모델 정의 (LG-000)

**LG-000-1. LessonInput (B로부터 받는 입력 스키마 + D의 피드백)**

오케스트레이터(D)를 통해 전달되는 C의 입력 데이터 구조.

json

```json
{
  "concept_name": "군집화",
  "unit_name": "동물의 생활",
  "achievement_code": "[4과02-01]",
  "analogy_text": "동물을 다리 개수나 사는 곳 같은 특징으로 무리 짓듯이...",
  "target_grade": 4,
  "inquiry_activities": ["동물 분류 기준 정하기"],
  "retry_feedback": null
}
```

최초 호출 시 retry_feedback은 null이며, D 검증 실패 시 D가 반환한 violations 상세 내용이 이 필드에 담겨 재입력된다.

**LG-000-2. LessonOutput (C가 생성하여 D로 전달하는 출력 스키마)**

json

```json
{
  "lesson_plan": {
    "motivation": "우리 주변 동물을 자유롭게 무리 지어보는 활동으로 시작...",
    "main_activity": "동물 사진 카드를 보고 학생 스스로 기준을 정해 무리 짓기...",
    "wrap_up": "AI도 이렇게 스스로 기준을 찾아 그룹을 나눈다는 것을 정리..."
  },
  "worksheet": [
    "동물 카드 5장을 보고 나만의 기준으로 두 그룹으로 나눠보세요."
  ],
  "expected_qna": [
    {
      "student_question": "기준이 여러 개면 어떡해요?",
      "teacher_response": "가장 눈에 띄는 공통점 하나를 먼저 골라볼까요?"
    }
  ]
}
```

#### 4. 세부 기능별 명세

**LG-001. 공식 교안 양식 준수 및 학습 목표·평가 기준 설계**

- 양식 반영: 공식 교수학습과정안(HWP) 양식의 항목 구조(단원명, 성취기준, 학습목표, 도입-전개-정리, 평가계획 등)를 시스템 프롬프트 템플릿에 그대로 반영한다.
- 학습 목표 및 상중하(ABC) 기준 수립: `achievement_code`로 교육과정 DB(A2가 구축한 벡터DB)를 조회하여 성취기준 원문·해설 데이터를 가져오고, 이를 근거로 상·중·하 평가 기준을 생성한다. DB 조회 결과에 없는 임의의 기준 문구는 사용하지 않는다.

**LG-002. 교안 4단계 구조화 및 Gemini 교사 발화 시뮬레이션**

- 동기유발: 친숙한 일상 비유로 흥미 유발.
- 본활동 (핵심): B가 매핑해 준 analogy_text와 inquiry_activities를 적극 활용. Gemini API 프롬프트 엔지니어링을 통해 교사가 현장에서 직접 구사할 수 있는 구어체 발화 스크립트와 오개념 지도 가이드를 포함한다.
- 정리: 핵심 개념 요약 및 AI 원리 연결.

**LG-003. 정합성 보장형 활동지 및 예상 문답 생성**

- 활동지 모호성 극복: 교육과정 원문의 탐구 활동(inquiry_activities)을 직접 연계하여 뜬구름 잡는 문항을 배제하고, 명확한 정답 키와 관찰 요소를 지닌 실습 문항을 작성한다.
- 예상 문답(expected_qna): 해당 수업에서 학생들이 자주 제기할 만한 질문과, 교사가 즉각 대응할 수 있는 가이드라인을 세트로 구성하여 교사의 실제 수업 준비 부담을 대폭 경감한다.

**LG-004. D 에이전트 피드백 루프(재귀적 재생성) 대응**

- 내용: D 에이전트가 검증 과정에서 passed: false 판정을 내리며 전달한 retry_feedback(violations 내용)을 입력받아, 위반된 학년 용어나 약화된 논리 관계를 실시간으로 식별하고 이를 교정하여 교안을 다시 생성한다. (max_retries: 3 기준 준수)
