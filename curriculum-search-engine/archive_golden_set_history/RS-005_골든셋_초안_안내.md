# RS-005 골든셋 라벨링 안내

`RS-005_골든셋_초안.csv` 검수 부탁드립니다.

## 배경

교육과정 검색 엔진(RS-004)이 실제로 잘 동작하는지 확인하려면 "AI 개념 X를 학년 Y에게 검색하면 단원 Z가 나와야 한다"는 정답 기준(골든셋)이 있어야 합니다. 이 CSV는 그 초안입니다.

## 만든 방식

1. Claude가 AI 개념 30개(분류, 예측, 군집화 등)와 각 개념의 대상 학년을 초안으로 만들었습니다.
2. 실제 ko-sroberta 임베딩 검색 엔진을 돌려서 학년별 후보 단원 top-5를 미리 채워뒀습니다 (후보1~5 열).
3. **사람 검수가 아직 안 된 상태**입니다 — 개념 자체, 학년 배정, 후보 목록 모두 필요하면 자유롭게 고치거나 행을 추가/삭제해주세요.

## 검수 방법

각 행(=하나의 "AI 개념 + 학년" 질의)에 대해:

1. 후보1~5 중 실제로 정답이라고 생각하는 단원의 `chunk_id`를 **"정답_chunk_id"** 열에 적어주세요 (예: `4수03-10`). 여러 개 정답이면 쉼표로 구분.
2. 후보 5개 중에 정답이 없으면, 직접 다른 `chunk_id`를 알고 있으면 적고, 모르면 **"없음"**이라고 적어주세요.
3. **"검수자"** 열에 이름 남겨주세요.
4. 애매하거나 의견이 갈릴 것 같은 항목은 "비고"에 메모.

## 분담

30행을 팀원 수에 맞춰 나눠서 진행하면 됩니다 (예: 2명이면 15개씩, 확신이 필요하면 겹치게 배정해서 교차 검증). 순서(no 열) 기준으로 나누면 편합니다.

## 검수 후

검수 끝난 CSV를 다시 주시면 `app/agents/curriculum_search`의 Recall@k 평가 스크립트(RS-005)를 만들어서 실제 정량 평가를 돌리겠습니다.

## 참고

- 1~2학년 대상 질의는 과학 후보가 아예 없습니다. 초등 1~2학년은 과학 과목이 없고 "슬기로운 생활"로 통합되어 있어, 지금 적재한 데이터(수학/과학)에는 해당 학년 과학 성취기준이 없기 때문입니다 (버그 아님).
- 모델/후보 생성 과정은 `RS-003_임베딩모델_벤치마킹.ipynb` 참고.
