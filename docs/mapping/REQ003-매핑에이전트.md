## 1. 역할

A1이 생성한 **StructuredConcept**와 A2가 검색한 **SearchResult**를 입력받아, 가장 적합한 교육과정 단원 1개를 선택하고 선택 근거, 학생 눈높이 비유, 신뢰도를 생성하여 C(교안 생성 에이전트)에 전달한다.

본 모듈은 **새로운 검색을 수행하지 않으며**, A2가 반환한 후보 목록 안에서만 LLM 기반 의미 판단(Reranking)을 수행한다.

또한 D가 전달하는 **PipelineContext**를 활용하여 대상 학년에 맞는 설명 수준을 유지하고, C가 바로 사용할 수 있는 **MappingResult**를 생성한다.

## 2. 입출력

### 입력 (A1 + A2 + D → B)

### A1 (StructuredConcept)

- concept_name
- category
- one_line_definition
- core_mechanism
- key_operations
- prerequisite_ideas
- everyday_examples
- caution_terms

### A2 (SearchResult)

**SearchResult**
- chunk
  - chunk_id
  - subject
  - grade_band
  - unit_name
  - domain
  - core_idea
  - achievement_code
  - achievement_text
  - explanation
  - inquiry_activities
  - source_page
- similarity_score
- rank
- reasoning (Optional)

> reasoning은 A2 검색 단계에서 생성된 참고 근거이다. B는 이를 참고 정보(Optional Context)로만 활용하며, 최종 단원 선택은 B의 독립적인 의미 기반 Reranking 결과를 따른다.

### D (PipelineContext)

- target_grade
- subject_hint (Optional)
- (D 재요청 시) excluded_chunk_ids

---

### 출력 (B → C)

**MappingResult**

- concept_name
- chunk_id
- achievement_code
- subject
- unit_name
- inquiry_activities
- mapping_reason
- analogy
- confidence
- criteria_scores
- flags

## 5. 매핑 기준

| 기준 | 가중치 |
| --- | --- |
| 의미 유사성 | 0.25 |
| 교육적 적합성 | 0.30 |
| 학생 이해도 | 0.20 |
| 비유 가능성 | 0.15 |
| 성취기준 정합성 | 0.10 |

최종 Confidence는 위 5개 항목의 가중 평균으로 계산한다.

- 0.75 이상 → 정상
- 0.50 ~ 0.75 → low_confidence
- 0.50 미만 → 재매핑 권고

## 7. 핵심 설계 원칙

- A1의 StructuredConcept와 A2의 SearchResult를 그대로 입력으로 사용한다.
- 새로운 검색은 수행하지 않는다.
- PipelineContext를 활용하여 대상 학년에 맞는 설명 수준을 유지한다.
- LLM은 후보 목록 안에서만 최적의 단원을 선택한다.
- A2의 reasoning은 참고 정보(Optional Context)로만 활용하며, 최종 선택은 B의 독립적인 의미 기반 Reranking 결과를 따른다.
- 선택 근거와 학생 눈높이 비유를 반드시 생성한다.
- MappingResult는 팀 공용 lib/types.py의 공식 인터페이스를 따른다.
- 출력은 JSON으로 구조화하여 C가 그대로 사용할 수 있도록 한다.
- 프롬프트, 가중치, LLM 호출을 분리하여 유지보수성과 확장성을 확보한다.
- Gemini API는 app/lib/gemini.py를 통해서만 호출하며, SDK를 직접 사용하지 않는다.
- API 실패 재시도는 공용 Wrapper에서 처리하고, 스키마 검증 실패 시 재생성 로직은 B에서 수행한다.
